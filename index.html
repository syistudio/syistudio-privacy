SYIStudio Pinterest App — Privacy Policy

Effective Date: November 7, 2026

This Privacy Policy describes how the SYIStudio Pinterest integration ("this app") accesses and uses data through the Pinterest API.

What This App Does

This is a personal-use automation that connects my own Etsy shop (SYIStudio) to my own Pinterest account. It is not a consumer product, an MCP/AI connector offered to others, or a service offered to any other user. Its only function is to post pins to Pinterest boards I own, each pin linking to one of my own Etsy listings, so my own products can be discovered on Pinterest.

Information We Access

Through the Pinterest API (OAuth), this app requests:

  • Read access to my own Pinterest boards, to select where a pin is posted
  • Write access to create pins on my own boards
  • Basic account information, to confirm which Pinterest account is connected

This app does not access, collect, or store data belonging to any other Pinterest user. It does not read or process personal information about followers, commenters, or any third party, and no one other than me can use or connect to this app.

How Information Is Used

The access above is used only to automatically publish pins — an image, title, description, and link — pointing to my own Etsy listings. Nothing is used for advertising, profiling, analytics, or any purpose beyond this single personal use case.

Data Storage and Security

Authentication tokens issued by Pinterest are stored locally, on my own computer, and are never uploaded, sold, or transmitted to any third party. No database of Pinterest user data is kept. The only record kept is a local log of which of my own pins have already been posted, used solely to avoid posting duplicates.

Data Sharing

No data is sold, rented, or shared with any third party, advertising network, or analytics service.

Your Control Over This

Because this is a single-user personal integration, access can be revoked at any time from the Pinterest account's app permissions settings. Revoking access immediately stops this app from reaching the Pinterest account.

Changes to This Policy

If this policy changes, the updated version will be posted at this same page.

Contact

Questions about this app can be sent via Etsy Conversations through the SYIStudio shop on Etsy.
